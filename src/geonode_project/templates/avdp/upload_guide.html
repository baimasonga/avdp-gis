{% trans "1. Prepare your data" %}

{% trans "Accepted formats" %}
{% trans "Format" %}{% trans "What to upload" %}
{% trans "Shapefile" %}{% trans "The .shp, .shx and .dbf files together (and the .prj, which defines the coordinate system), or a single .zip containing them." %}
GeoPackage{% trans "A .gpkg file. Each vector table becomes a dataset." %}
GeoJSON{% trans "A .geojson or .json file. GeoJSON is defined in WGS 84 (EPSG:4326)." %}
KML / KMZ{% trans "A .kml file or a .kmz archive." %}
CSV{% trans "A .csv with point coordinates in columns named lat/lon or latitude/longitude, or a WKT geometry column." %}
GeoTIFF{% trans "A .tif / .tiff raster with embedded georeferencing." %}
  • {% trans "Use WGS 84 (EPSG:4326) where possible. Always include the coordinate system definition (.prj for shapefiles)." %}
  • {% trans "Use short file names with letters, numbers and underscores only, e.g. water_points_2026.shp." %}
  • {% trans "Check geometries are valid and attribute names are meaningful before uploading." %}
  • {% trans "Archives that contain absolute paths, '..' path segments, symbolic links or extreme compression ratios are rejected for security reasons." %}

{% trans "Spreadsheet templates" %}

{% blocktrans %}Partners without GIS software can fill in a spreadsheet: one row per site, coordinates in decimal degrees (for example latitude 7.964, longitude -11.738). Download a template, fill it in with Excel or LibreOffice, and save it as CSV (UTF-8). Keep the column names; leave optional cells empty rather than writing "n/a".{% endblocktrans %}

{% trans "Spreadsheet templates" %}
{% trans "Template" %}{% trans "Main columns" %}
{% trans "Water points" %}water_point_type, status (Functional / Needs repair / Not functional), beneficiaries, year_built
{% trans "Grain stores" %}store_type, capacity_t, status, managed_by
{% trans "Farmer groups" %}group_type, members, women_members, main_crop, registered (yes / no)
{% trans "Input distribution sites" %}input_type, quantity, unit, distribution_date (YYYY-MM-DD), beneficiaries
{% trans "Demonstration plots" %}technology, crop, area_ha, start_date, farmers_trained
{% trans "Farm plots (as points)" %}farmer_group, crop, area_ha, season
{% trans "Feeder roads" %}{% trans "wkt_geom holds the road line, e.g. LINESTRING(-11.74 7.96, -11.70 7.99); surface, condition, length_km" %}

{% blocktrans %}Every template also has district, chiefdom, photo_url and remarks columns. To practise, upload the practice file (eight invented water points). Do not enter names of individual farmers or other personal data.{% endblocktrans %}

{% trans "2. Upload" %}

{% if request.user.is_authenticated %} {% blocktrans %}Go to Upload Data, drag in your files and start the upload. Processing continues in the background; the dataset appears under your datasets when it is ready.{% endblocktrans %} {% else %} {% blocktrans %}Sign in with an editor account to upload. Accounts are created by portal administrators.{% endblocktrans %} {% endif %}

{% trans "What happens after the upload" %}

  • {% trans "The portal styles the dataset from its contents: theme symbols when the name suggests one (water points, stores, roads…), colours from a status or type column, labels when zoomed in, and a readable pop-up." %}
  • {% blocktrans %}It runs a data check. Open the dataset: the note at the bottom left says "Data check: no issues" or lists what to look at, with examples:{% endblocktrans %}
    • {% trans "Problem: features with no location, or outside Sierra Leone's districts (at sea or abroad); the check says when latitude and longitude look swapped." %}
    • {% trans "Warning: invalid shapes, two features at exactly the same place, a district label that disagrees with where the feature lies, and columns that are mostly empty." %}
    • {% trans "Note: optional columns left empty, and labels that are not district names." %}
  • {% trans "Fix problems in your file and upload it again (or correct them in the browser, below), then delete the faulty version." %}

{% trans "3. Describe the dataset (metadata)" %}

{% trans "Open the dataset, choose Edit → Edit metadata, and complete at least:" %}

  • {% trans "Title and abstract (what the data shows and why it was collected)." %}
  • {% trans "AVDP dataset category (crop production, farmer organizations, rural infrastructure, water infrastructure, storage facilities, agricultural input distribution, or demonstration and extension)." %}
  • {% trans "Data status: verified, provisional or synthetic demonstration." %}
  • {% trans "Data source / attribution, point of contact and owner." %}
  • {% trans "Geographic coverage (region), reference or collection date and maintenance (update) frequency." %}
  • {% trans "Licence and any access or use restrictions." %}

{% trans "District names stored in attribute tables are labels supplied with the data. They are not a verified spatial assignment unless the metadata says the data was checked against official district boundaries." %}

{% trans "4. Style and share" %}

  • {% trans "The portal styles new vector datasets automatically: features are coloured by a status or type field when there is one, labelled when you zoom in, and given a readable pop-up." %}
  • {% trans "In a map, open the layer's settings and the Style tab to switch between the default style and alternatives: single symbol, heat map, clusters, or sized/shaded by a number field." %}
  • {% trans "Edit → Edit style lets you change symbols and colours; the legend updates automatically." %}
  • {% trans "Share lets you grant view, download, edit or manage rights to individual users or groups (for example AVDP Viewers or AVDP Editors)." %}
  • {% trans "Only make a dataset public when its owner has approved it for public release." %}

{% trans "5. Correct data in the browser" %}

{% blocktrans %}Members of AVDP Editors (and owners) can fix individual records without uploading again: open the dataset, choose Edit → Edit data, select a feature in the table or on the map, change its values or move it, and save. AVDP Viewers can look and download but cannot change anything.{% endblocktrans %}

  • {% trans "Use it for small corrections: a wrong status, a misspelt name, a point in the wrong place." %}
  • {% trans "For many changes, correct the source file and upload a new version instead, so your files and the portal stay the same." %}
  • {% trans "After larger changes an administrator can re-run the data check (manage.py avdp_quality_check)." %}

{% trans "6. Photos" %}

{% blocktrans %}A column named photo_url (or photo) is shown as a picture at the top of the feature pop-up. Upload site photos as Documents (Upload Data → document), share them like the dataset, and paste each photo's address into the row. Photos of people need their consent; prefer photos of the facility.{% endblocktrans %}

{% trans "7. Districts, summary and dashboard" %}

  • {% trans "The official district boundaries (Government of Sierra Leone / OCHA, 16 districts) are a dataset in the catalogue; add them to any map." %}
  • {% trans "The District summary counts features per AVDP category in each district, for datasets that have an AVDP dataset category and are shared with AVDP Viewers or the public. Set the category in the metadata so your data is counted." %}
  • {% blocktrans %}The AVDP district overview dashboard shows the totals. Administrators refresh both after new data is shared (manage.py avdp_district_summary, then avdp_dashboard).{% endblocktrans %}
